# Čitaonica

Javni RSS feed sa dnevnim tekstovima na srpskoj latinici, pisanim da se lakše čitaju (kratki pasusi, podebljane ključne ideje, 5–10 minuta).

- Feed: https://icemonk79.github.io/citaonica-rss/feed.xml
- Naizmenično: sažeci netažne literature i kratka objašnjenja tema (pomorski IT, mreže, zdravlje mozga i krvnih sudova, dugovečnost, ADHD i fokus, osnove kriptovaluta, istorija i nauka).
- Ikonice u feedu su [Twemoji](https://github.com/jdecked/twemoji) grafike, CC-BY 4.0; vidi `icons/NOTICE.txt`.
